# Ollama embedding probe — 2026-10-18

Локальное измерение для [R-4](../R-4-ollama-local-probe.md); не реализация Engram.

- `probe.executed.py` — точный исполнявшийся Python-скрипт.
- `metadata.json` — оборудование, версия, модель/digest, API show/ps, параметры смешанной нагрузки.
- `requests.jsonl` — все 204 вызова: время клиента, длительности API в наносекундах, число токенов, проверка размерности/нормы. Векторы не сохраняются.
- `memory.json` — выборки процессов/RSS примерно каждые 0,5 с.
- `summary.json` — результаты скрипта. Одиночные документы сгруппированы по полному label, поэтому по одному наблюдению; R-4 объединяет по размеру/языку и берёт медиану трёх.
- `download.json` — итог загрузки; время отдельно от вычислительной пробы.
- `sha256.json` — SHA-256 исходных артефактов и скрипта.

Для воспроизведения: скопировать скрипт, изменить OUT на новый пустой каталог, MODEL оставить точным tag; обеспечить установленную модель и пустой API ps (например, дождаться естественной выгрузки). Проверить Python и локальный адрес Ollama. Скрипт использует macOS ps/sysctl и исходные пути Python из текущего окружения; на другой системе адаптировать команды и записать изменения отдельно. Не запускать оригинал повторно в тот же каталог: requests.jsonl дописывается.

Проба: 2 с baseline; первый документ 2 КБ; по 3 последовательных документа каждого размера 500/2000/8000 байт на EN/RU; 10 коротких запросов; смешанная подача 150 запросов и 25 документов за 15 с; 2 с после. Клиент допускает до 40 одновременно ожидающих HTTP-вызовов, но не создаёт такую нагрузку постоянно. При достижении этой границы записывает пропуски; в данном запуске их 0. Все запросы используют truncate:false и keep_alive:5m, остальные runtime options — существующие значения Ollama.

RSS включает GUI, server и llama-server runner; сумма RSS не равна полной физической памяти. CLI после пробы сообщил 100% GPU. Другие приложения не останавливались; выделения памяти GPU и фоновые помехи отдельно не измерены. Результаты одного запуска не являются SLA или CPU-only бенчмарком.
