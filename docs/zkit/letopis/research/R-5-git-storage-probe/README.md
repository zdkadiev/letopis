# Git storage probe — 2026-10-18

Скрипты и первичные данные для [R-5](../R-5-git-storage-probe.md).

- `probe.executed.py`: точный исполнявшийся генератор и основной замер двух временных репозиториев.
- `pack_refs_probe.executed.py`: последующая упаковка refs и повторная полная проверка.
- `metadata.json`: версия Git, ОС, seed/характер генератора, начальные условия.
- `summary.json`, `point-result.json`, `rewrite-result.json`: размеры и времена до/после repack, исходные выводы count-objects, результаты проверок.
- `packed-refs-result.json`: отдельный замер после pack-refs.
- `*-objects.json`: OID, тип, размер и SHA-256 ожидаемого содержимого каждого объекта.
- `*-snapshots.json`: все 201 ref/tree для каждого варианта.
- `sha256.json`: SHA-256 скриптов и исходных JSON.

Для повтора на macOS с Python и Git:

```sh
mkdir -p /private/tmp/engram-git-probe-20261018
python3 probe.executed.py
python3 pack_refs_probe.executed.py
```

Запускать последовательно из каталога копий скриптов. Первый создаёт новый уникальный временный каталог и сохраняет его путь в /private/tmp/engram-git-probe-20261018/current-run.txt; второй читает этот путь. Не запускать параллельные копии с общим файлом указателя. Новые результаты не дописываются в сохранённые документы. Рабочие репозитории повтором не изменяются. Временные репозитории исходного замера не включены в документы; они воспроизводятся генератором.

Корпус — 30 файлов по 60 000 байт, каждый из 30 непрерывных фрагментов по 2000 байт. Содержимое — английские слова из ограниченного словаря, разметка и стабильные псевдослучайные UUIDv4. Валидность формата Engram и качество знаний не проверялись. В каждом профиле 200 шагов по пять разных файлов; выбираемый элемент меняется каждые шесть шагов. Файлы и их размер остаются постоянными.

Point меняет десятизначное значение внутри элемента; rewrite заново генерирует его текст, сохраняя ID. Оба записывают полный файл. Снимки — tree objects с отдельной ref, без commit objects и reflog-истории коммитов. Системный/глобальный Git config исключён; auto GC/maintenance отключены в тесте. В остальном используются настройки Git по умолчанию данной версии; долговечность при отключении питания не проверяется.

Проверяются refs и байты всех объектов через cat-file --batch перед repack, после repack и после pack-refs. SHA-256 сверяется с данными, рассчитанными при генерации; Git OID дополнительно пересчитывается из типа/размера/байтов. Fsck обязан завершиться успешно.

Размеры logical_bytes — сумма st_size файлов; allocated_file_bytes — сумма st_blocks × 512. Каталоги и полная стоимость файловой системы не входят. Рабочие Markdown-файлы учитываются отдельной метрикой; они не включены в размер .git.
