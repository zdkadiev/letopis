# Адаптация roadmap и карточек к zkit 0.2.5

Дата: 2026-10-19. Область: план и его проверки, без реализации продукта или новых замеров. Основание: просьба пользователя исправить [замечания аудита](roadmap-zkit-0.2.5-review-2026-10-19.md), сохранив полное недельное раскрытие, YAGNI и KISS; [D-88](../../decisions.md#D-88).

## Результат

[Roadmap](../../roadmap.md) содержит **45 подробно описанных задач в 8 эпиках**, 5 фаз и 5 gates. Все задачи по-прежнему planned. Эпики — контейнеры, поэтому часы не удваиваются. Прежние EP-1…EP-7 сохраняют смысл; EP-8 объединяет начальные TK-1…TK-6. У эпика есть epic.md, у каждой задачи — один файл в его tasks/.

Сохранены ID задач, фазы, зависимости, все best/expected/worst оценки и каждое недельное распределение часов: **204 / 372 / 672 ч**, expected **372 ч / 38 недель** при 10 ч/неделю; последняя неделя 2 ч, финальная задача TK-45. Изменено владение уже запланированной работой и устранены неоднозначные формулировки. Оценки остаются инженерными допущениями и пересматриваются при failed gate, а не выдаются за измеренную скорость.

## Проверки

Команды:

```text
python3 -B <zkit-0.2.5>/skills/requirements/scripts/link_docs.py <project>
python3 -B <zkit-0.2.5>/skills/roadmap/scripts/check_roadmap.py <project>
python3 -B <project>/roadmap_schedule.py --check
```

Новый checker и локальная проверка дают exit 0. У нового checker нет ERROR/WARN: 0 непокрытых Must, 0 незапланированных drills, 0 отсутствующих карточек. Локальная проверка подтверждает 45 задач/карточек, 38 недель, максимум 10 ч/неделю, 2 ч последней недели, TK-45 в конце; ошибок зависимостей/переходов фаз нет. Отдельно сравнены все недельные allocations с исходной редакцией — совпадают.

В изолированных копиях отклонены восемь повреждений: отсутствующая карточка; неверный Epic; отсутствующий раздел границ; устаревшая оценка карточки; отсутствующий handoff; неверная сумма часов эпика; отсутствующая приёмка; устаревшая недельная таблица. Штатный и негативные прогоны выполнялись раздельно.

Проверены существование файлов по реальным Markdown-ссылкам изменённых документов, карточек и эпиков, синтаксис Python helper, сохранность всех остальных исходных документов/моделей/измерительных артефактов. Исторический аудит сохранён с прежним вердиктом; в нём обновлены только ссылки на перемещённые карточки. Старые check results не переписаны как новые успехи.

При нормализации ссылок выявлено поведение bundled `link_docs.py`: он удаляет ссылки на любые имена, оканчивающиеся на `index.md`. Для карточки выбран slug `TK-25-reindexing.md`; после этого нормализатор сохраняет ссылки. Код установленного zkit не изменялся.

Числа, команды, полные результаты, негативные случаи и финальная проверка установленного проекта: [checks JSON](roadmap-zkit-0.2.5-adaptation-checks-2026-10-19.json). Автоматические проверки показывают структуру и согласованность плана; смысл границ дополнительно проверяет независимый reviewer.
