## 3. Что сделать

1. Создать продуктовый crate с `rust-toolchain` 1.95.0 и edition 2024 (D-96), согласованную схему служебной БД и Rust storage ports.
2. Настроить WAL/FULL/fullfsync/FK и адаптеры graph, FTS5, files с ошибками файлов и vectors.db (vec1, embed_failures).
3. Собрать vec1 статически в бинарник продукта (D-96): build.rs с `cc` компилирует закреплённый `ext/vec1` вместе с bundled SQLite, регистрация через `sqlite3_auto_extension`, feature `load_extension` выключен. TK-1 доказал только загрузку отдельного файла.
4. Проверить ключи/CHECK, атомарные units и отсутствие копий исходных текстов в БД.

Начальная схема SQLite и storage adapters для всех согласованных сущностей.
