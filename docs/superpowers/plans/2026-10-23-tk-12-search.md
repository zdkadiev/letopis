## Review Focus

1. **Literal queries containing OR/NEAR/quotes, Cyrillic, accents or only punctuation:** treated as data; malformed FTS syntax never escapes. Task 3 token/ranking tests and Task 4 real CLI tests pin this.
2. **First dimension establishment or model reset while HTTP/read view is active:** no new-model vector or diagnostic contaminates the old view; Task 2 captured-query tests and Task 3 real SQLite/HTTP interleavings pin this.
3. **Invalid current Markdown retaining an old valid index row:** search reports stale and inspect fails validation instead of returning old coordinates. Task 1 inspection and Task 3 freshness tests pin this.
4. **Valid but unsupported filters or path-shaped source selectors:** never ignored or guessed from syntax; malformed input remains distinct. Task 1 source membership and Task 4 parsing/pre-I/O tests pin this.
5. **Failure/lost stdout after refresh or Git capture, then retry:** prior publication may remain, but corpus/index/user refs stay unchanged and no partial JSON is emitted. Task 4 real binary tests and Task 5 copied-executable/schema capture pin this.
