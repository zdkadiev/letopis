## Review focus

1. Ten commands all finish their free-lock probes before any drain acquires its lock: launcher probes alone cannot prevent multiple active drains; the child-side guard must do so.
2. The launcher returns or dies while a drain is paused: no inherited lock/pipe may hold publication open, block the launcher response, kill the detached child or prevent the next owner after death.
3. A lock file contains a stale or unrelated live PID: it cannot prevent acquisition of a free kernel lock, bypass a held lock, or cause signalling of that PID.
4. SIGINT hits a blocked waiter, an active pre-commit publisher/reindex, or a process after commit: exact old/new state and survival of unrelated processes must be observed independently.
5. Spawn fails or the caller crashes between probe and spawn: publication still succeeds, embedding work remains queryable, and a later command can start the drain without manual lock-file repair.

Scratch interfaces:

```rust
enum Launch { NoWork, AlreadyRunning, Spawned(u32), Failed(String) }
fn launch_if_needed(root: &Path, executable: &Path, checkpoint: &mut dyn FnMut(&str) -> CheckResult<()>) -> CheckResult<Launch>;
fn command(root: &Path, reindex: bool, executable: &Path, checkpoint: &mut dyn FnMut(&str) -> CheckResult<()>) -> CheckResult<Launch>;
fn run_drain(root: &Path, provider: &mut dyn FnMut(&str, &str) -> CheckResult<Vec<f32>>, checkpoint: &mut dyn FnMut(&str) -> CheckResult<()>) -> CheckResult<bool>;
```

`command` first consumes `letopis_publication_checks::publish`, then calls `launch_if_needed`. Launch checks TK-3's `capture_config/attached/pending`; a free probe is released before spawning `runtime ROOT drain` in a new session, with stdin/stdout/stderr null. Spawn failure returns `Launch::Failed` without undoing publication. `run_drain` returns false immediately when the embed lock is busy, otherwise holds an owned File lease around `letopis_embedding_checks::drain`. Readiness hooks identify the child PID/event and wait for parent acknowledgement; only fixture builds use the test control socket.
