## Review Focus

1. **Database-path aliases and literal special characters:** cache/vectors must be different files even through symlinks/hardlinks; quotes, Unicode, and question marks must remain filenames, not SQLite URI/SQL syntax. Owned by Task 2.
2. **Existing partial/unknown schemas and competing initializers:** reopen must preserve valid data, reject incompatible state without destructive recreation, and return a typed busy/error or a valid initialized state. Owned by Task 2.
3. **A caller catches a failed mutation then calls commit:** earlier writes must still roll back; unsigned overflow and late FTS/native failures cannot leave partial projection or key/vector pairs. Owned by Tasks 3 and 4.
4. **Reads and model changes interleave:** old pinned readers retain their own metadata/vector state, new readers see the reset, and identity mismatch cannot return a wrong-model vector. Owned by Task 4.
5. **Restart/exhaustion and diagnostics containing payloads:** reserved attempts survive reopen, exhausted work cannot reserve again, and public errors do not reveal raw SQLite messages, text markers, SQL, or credentials. Owned by Tasks 3 and 5.
