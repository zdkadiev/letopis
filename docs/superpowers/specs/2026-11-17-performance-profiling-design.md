Missing dependencies/profiler/entitlements are recorded blockers; no production manifest edits to work around them.

Baseline launches one measured command at a time; no parallel benchmark matrix or throughput sweep. Explicitly supply closed JSON stdin; reset/copy fixtures outside timed interval. Preserve existing defaults: two conditioning calls then20 measured cheap calls, or3 measured expensive calls; existing >2s adaptive classification and mutation/full/100k expensive classification apply. Record first-observed invocation separately. Budget reductions require explicit requested/actual n and skip reasons, never silent default changes. First-run means first observed invocation, **not OS cold cache**. Fresh-cache scenarios reset cache each repeat; initialized/no-op scenarios preserve specified prepared state. Record all samples, median/min/max and sample standard deviation; no p95 below100 successes or p99 below1000.

On macOS use per-child `wait4` resource usage plus monotonic elapsed wall time (or independently validated OS-equivalent measurement): user/system CPU seconds, maximum RSS bytes with documented platform conversion, minor/major faults, input/output block operations with platform semantics. Unavailable or zero counters remain explicitly unavailable/OS-reported, never invented byte I/O. Preserve OS raw fields. Validate against `/usr/bin/time -l` on controlled CPU/sleep/memory helper processes outside product timings. MaxRSS is process peak resident memory, **not allocation profiling**, retained heap, sum of thread maxima, or instantaneous combined process-tree peak.

Save raw profile, launch command, interval, exit, symbolication evidence, and profile wall time; do not mix sampled timings into baseline statistics.
