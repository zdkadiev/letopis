## Verified reuse limits

- Existing `prepare_fixture` writes disabled **Ollama** config; `FakeProvider` only serves native `/api/embed`. Reuse generic generator/measurement helpers, not enabled-provider setup unchanged. Local OpenAI-compatible fixture needs explicit configuration, indexed `/v1/embeddings` response and nonempty synthetic OPENAI_API_KEY: missing key fails before HTTP. [Setup](../../tests/performance/scenarios.py), [fake](../../tests/performance/provider.py), [actual client](../../src/embedding/provider.rs).
- Existing report validator rejects warnings, findings, flags and held locks; search expects exactly one ID, inspect one ID, traversal specialized edge set. Index only requires positive revision. New fault/empty/busy/batch cases need scenario-owned independent oracles, not blanket acceptance. Existing generator validator is also topology/layout-specific. [Validator](../../tests/performance/report.py), [generator validator](../../tests/target_corpus/validate.py).
- `prepare_scenario.refresh_one` changes every matching body token in one file (~30 elements), not one knowledge node. Inspect oracle assumes `##` anchored sections; traversal oracle assumes generator's first neighborhood. They are not general-purpose expectations for rewritten graphs/file elements. [Primary helpers](../../tests/performance/scenarios.py).
- R-6 used placeholder OIDs/hashes, synthetic 768-d vectors and SQL primitives without inference/fusion/CLI/provenance. Its latency is not a CLI baseline. R-8 no-index assumptions are historical; current mode is flat/cos. R-7 verifies protocol subset, not arbitrary compatible server semantics. [R-6](../../docs/zkit/letopis/research/R-6-sqlite-capacity-probe.md), [R-8](../../docs/zkit/letopis/research/R-8-durability-and-search-primitives.md), [R-7](../../docs/zkit/letopis/research/R-7-embedding-api-compatibility.md), [mechanics](../../docs/zkit/letopis/mechanics.md).

- **MEM-01 P1:** 10k nodes,32 internal neighbors/node; traverse node limit10k and edges omitted versus edge_limit320k. Separate queue/visited cost from edge materialization/output. Include incoming high-fan-in star. Search cannot return10k: cap100. [Graph](../../src/service/graph.rs).

Stage parser/SQLite limits; preserve actual error rather than demand unlimited success. Bounded candidate union does not bound query/source-binding/validation/native scan work. [Search](../../src/service/search.rs).

Keep raw payload arithmetic/DB size separate from observed CLI RSS and mock server resource scope. [R-6 limits](../../docs/zkit/letopis/research/R-6-sqlite-capacity-probe.md).
